# 课程总结

## LangChain生态

<img src="https://resource.duyiedu.com/yuanjin/202608052258029.png" alt="image-20260805225830903" style="zoom:50%;" />

- **LangGraph**：提供了工作流运行必要的功能，包括节点、边、中断、时间旅行等等

- **LangChain**：统一了模型、消息、工具格式，并预置了 Agent 工作流，同时提供了中间件机制

- **DeepAgent**：预置了大量中间件，某些中间件需要后端

- **Agent Server**：实现 Agent Server Protocal 协议

- **LangSmith**：提供了Agent跟踪、图调试、部署等基础设施

  

## Agent的技术选型

|            | 代表                                                         |
| ---------- | ------------------------------------------------------------ |
| **高代码** | `LangChain生态`、`OpenAI Agents SDK`、`AutoGen`、`AgentScope` |
| **低代码** | `LangFlow`、`Dify`、`n8n`、`Coze`                            |
| **无代码** | `扣子 Bot`、`Copilot Studio`、`Agentforce`                   |
