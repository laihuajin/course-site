# 系统设置

## 落地流程

### 模型层

1. 复制模型代码

2. 更新`apps/web-service/app/model/__init__.py`，新增

```python
from app.model import setting_group  # noqa
from app.model import setting  # noqa
```

3. 迁移

```shell
make db-migrate message="add_settings"
make db-upgrade
```

### 业务层

1. 复制DTO
2. 复制service
3. 复制对service的集成测试
4. 复制对service的单元测试
5. 运行新增的测试

### API层

1. 复制API
2. 复制main
3. 复制对API的e2e测试
4. 复制对API的集成测试
5. 运行新增的测试
6. 检查接口文档
7. 手动测试一次
8. 运行冒烟测试
9. 提交
