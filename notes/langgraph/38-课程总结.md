# 课程总结

## LangChain Core

| 核心概念         | 备注                 |
| ---------------- | -------------------- |
| `Runnable`       | 一个可以被执行的对象 |
| `RunnableConfig` | 执行时的配置         |
| `BaseMessage`    | 消息的父类           |

## LangGraph

| 核心概念       | 备注                     |
| -------------- | ------------------------ |
| `StateGraph`   | 根据状态定义并编译图     |
| `State`        | 节点之间共享的数据       |
| `Reducer`      | 定义状态字段的更新方式   |
| 节点           | 执行具体任务             |
| 边             | 定义节点之间的流转关系   |
| 超步           | 并行执行当前可运行的节点 |
| `Checkpointer` | 按线程持久化图状态       |
| `ToolNode`     | 执行模型调用的工具       |
| 子图           | 将一张图嵌入另一张图     |
| `Command`      | 更新状态并控制流程       |
| `Thread`       | 一系列检查点的存储容器   |
| `Store`        | 跨线程的存储             |
| `interrupt`    | 暂停图并等待外部输入     |
| `Send`         | 动态创建并行分支         |

## LangChain

| 核心概念 | 备注                                          |
| -------- | --------------------------------------------- |
| 模型     | 统一访问接口，不同的Provider实现              |
| 消息     | 统一的消息格式封装                            |
| 工具     | 提供`@tool`装饰器，将函数转换为`Runnable`工具 |

## Agent Server

| 核心概念               | 备注                                                         |
| ---------------------- | ------------------------------------------------------------ |
| `langgraph-cli[inmem]` | 提供`Agent Server`的管理命令                                 |
| `langgraph-api`        | 提供`Agent Server`的核心实现                                 |
| `Assistant`            | Agent = 图 + 配置                                            |
| `Thread`               | 独立存储的线程配置                                           |
| `Run`                  | 运行一个轮次，需要`Assistant` + `Thread`<br />可取消任务<br />可处理线程内并发 |
| `Crons`                | 计划任务                                                     |
| `Store`                | 跨线程存储                                                   |
| `A2A`                  | 实现了`A2A`协议                                              |
| `MCP`                  | 将`Agent`暴露为`MCP`工具                                     |
| `System`               | 提供系统信息                                                 |
| `Streaming`            | LangGraph Event Streaming V3<br />目前接口有BUG，暂时不用    |

## LangSmith

| 核心概念 | 备注                       |
| -------- | -------------------------- |
| 追踪     | Runnable运行期间会上报消息 |
| `Studio` | 调试图的运行               |

## Agent Chat

提供一个UI界面测试Agent的能力。
