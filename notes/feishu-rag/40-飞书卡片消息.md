# 飞书卡片消息

## 创建飞书卡片

```python
from deal_pilot.feishu.api import Card

# 创建飞书卡片消息
card = await Card.create({
    "schema": "2.0",
    "body": {
        "elements": [
            {"tag": "markdown", "element_id": "answer", "content": "正在思考..."}
        ]
    },
}, receive_id=open_id)
```

创建卡片时，需要传递：

- **卡片描述**

  卡片描述是一个JSON格式，它描述了卡片的所有信息，包括但不限于卡片的内容和样式。

  该 JSON 格式的 Schema 参考[飞书官方文档](https://open.feishu.cn/document/feishu-cards/card-json-v2-structure)

- **接收方ID**

  默认为用户的 OpenID

## 流式更新卡片内容

```python
for chunk in ["你好！", "这是一段", "**流式输出**。"]:
    await asyncio.sleep(1)
    text += chunk
    await card.stream_text("answer", text)
```

## 完成卡片更新

```python
card.finish()
```
